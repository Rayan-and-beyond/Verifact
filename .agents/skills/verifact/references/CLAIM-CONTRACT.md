# Claim contract

Call an Verifact assessment evidence-backed only when:

1. collection stayed inside the frozen, read-only scope;
2. selected manifests and artifacts pass size and SHA-256 checks;
3. evidence gaps are visible in coverage;
4. every validated host claim points to local evidence and an exact record;
5. the exact final finding received a declared review pass, with same-agent fallback and self-attested identity disclosed;
6. rejected and inconclusive results remain recorded;
7. report inputs and outputs pass provenance checks.

Never claim complete vulnerability coverage, continuous monitoring, exhaustive malware detection, proof of compromise, or proof that the host is secure.
